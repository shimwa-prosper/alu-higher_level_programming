The ``1-my_list`` module
========================

Using ``MyList``
----------------

Import the class:

    >>> MyList = __import__('1-my_list').MyList

It is a subclass of list:

    >>> issubclass(MyList, list)
    True

Empty list:

    >>> my_list = MyList()
    >>> my_list.print_sorted()
    []

Unsorted list, and the original stays unchanged:

    >>> my_list = MyList()
    >>> my_list.append(3)
    >>> my_list.append(1)
    >>> my_list.append(2)
    >>> my_list.print_sorted()
    [1, 2, 3]
    >>> print(my_list)
    [3, 1, 2]

Already sorted list:

    >>> my_list = MyList([1, 2, 3])
    >>> my_list.print_sorted()
    [1, 2, 3]

Negative numbers:

    >>> my_list = MyList([3, -1, 2, -5])
    >>> my_list.print_sorted()
    [-5, -1, 2, 3]

Duplicates:

    >>> my_list = MyList([2, 1, 2])
    >>> my_list.print_sorted()
    [1, 2, 2]
